# Featured Projects

### 🌊 AquaChain
*B.Tech capstone · Cloud & DevOps Lead, 4-person team*

A serverless AWS platform for real-time water-quality monitoring, deployed across **17 CloudFormation stacks** (CDK / Python) covering ingestion, compute, data, security, and monitoring.

- Real-time pipeline: **ESP32 → IoT Core → Lambda → DynamoDB** with **620ms p95** end-to-end latency and **99.2% uptime** over 3 months of load testing
- XGBoost contamination classifier trained on SageMaker (**94.2% accuracy**)
- GitHub Actions CI/CD for Lambda packaging and CDK deploys across dev, staging, and prod

`AWS CDK` `Lambda` `IoT Core` `DynamoDB` `SageMaker` `GitHub Actions` `Python`

[![Repo](https://img.shields.io/badge/View-AquaChain-6CE4F7?style=for-the-badge&logo=github&logoColor=black)](https://github.com/FoldedOdin/AquaChain)

### ⚙️ OdinRun (formerly PipelineOS)
*Solo · Open source · v1.0.0*

A self-hosted CI/CD platform with intelligent failure diagnosis.

- Full CLI (`./odinrun start/stop/status/logs/doctor`) and a guided web setup that gets a working pipeline running in **under 60 seconds**
- Event-driven core with live CPU/memory telemetry streamed from the Docker Engine API to a React dashboard over WebSocket
- Resilient fleet scheduling with 60-second claim-lease expirations to prevent hung or queued runs
- Rule-based auto-remediation plus **local-first AI root-cause analysis** (Ollama, 100% on-prem) with optional OpenAI support

`Docker` `Redis` `BullMQ` `WebSocket` `GitHub Webhooks` `Python` `Ollama`

[![Repo](https://img.shields.io/badge/View-OdinRun-6CE4F7?style=for-the-badge&logo=github&logoColor=black)](https://github.com/FoldedOdin/OdinRun)

### 🏥 KPM Clinic
*Freelance · Next.js 14 + Sanity CMS*

A production website for a solo healthcare practice, with a headless CMS so non-technical staff can update services on their own, plus an automatic static-content fallback that keeps the site online if the CMS is unreachable.

`Next.js 14` `TypeScript` `Sanity` `Netlify` `Terraform` `GitHub Actions`

[![Live Site](https://img.shields.io/badge/Live-kpm--clinic.com-6CE4F7?style=for-the-badge&logo=vercel&logoColor=black)](https://kpm-clinic.com/)
